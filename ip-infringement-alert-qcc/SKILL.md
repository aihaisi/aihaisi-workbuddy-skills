## SKILL 定位

产品上市 / 合作签约前的 IP 侵权风险预警工具。V2.0 新增历史商标相似挖掘能力。

## 工作流维度

1. 目标企业 IP 组合 vs 本方产品的覆盖范围对比
2. 商标近似检索（含文字 / 图形）
3. 专利权利要求覆盖范围分析
4. **V2.0 新能力：历史商标相似挖掘**（qcc-history get_historical_trademark —— 扩大相似商标搜索范围到历史记录）
5. IP 诉讼历史（get_judicial_documents 案由过滤）

> **裁判文书详情下钻（按需单篇 · 2026-06-27）**：对识别出的重点 IP 侵权案件，如需确认侵权认定 / 判赔金额 / 权利要求比对说理，先由 `mcp__qcc-risk__get_judicial_documents` 列表拿「文书ID」→ 单篇调 `mcp__qcc-risk__get_judicial_document_detail`（section 默认 `core` = 本院认为 + 判决结果）。单轮 ≤ 3 篇；判赔金额引文书原文，不臆测、不做胜诉率预测（铁律 6）。

> 📌 **year 留空拿全量 · 禁逐年循环（防 year 散弹枪 · 2026-07-01）**：`get_judicial_documents` 等带 `year` 过滤参数的诉讼类工具，**取 IP 诉讼全量时 `year` 一律留空——接口在 year 缺省时即一次返回全部年份**。**严禁为"覆盖多年"而逐年（2024、2023 … 直至成立年）循环调用同一工具**：那是无效散弹枪，单次运行可产生数十次冗余调用。`role`（原告 / 被告）、案由等其他过滤参数同理，取全量时留空；仅当明确限定某一年时才传 `year`。

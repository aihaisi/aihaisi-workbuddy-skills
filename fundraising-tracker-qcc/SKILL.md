# 融资历史追踪

融资动态追踪Skill - 企查查MCP增强版。
追踪企业融资历史、估值变化、投资方背景，辅助VC/FA进行投资决策。

核心功能：
- 融资历史：历次融资时间、金额、投资方、估值
- 估值趋势：估值变化曲线、估值合理性评估
- 投资方分析：投资机构背景、领投/跟投策略
- 竞品融资：同行业企业融资动态对比
- 融资信号：潜在融资需求信号识别

适用场景：VC投资前研究、FA项目推介、企业融资规划、投资组合监控。

使用方式：/fundraising-tracker-qcc 企业名称 [--peer 竞品企业] [--sector 行业]

**命令**：`/fundraising-tracker-qcc` · **MCP 工具集**：`QCC MCP (Company/Operation)`

## 股比 / 持股 / 表决权原值纪律（全报告强制）

- 企业数据中的直接持股、总持股（含间接）、间接持股、最终受益股份、表决权等比例，必须逐字引用本次接口返回的原始字符串并保留全部小数位；接口返回 `X.XXXX%` 时，禁止改写为 `X.XX%`、禁止补零改写或四舍五入。
- 同一指标在执行摘要、一句话结论、KPI、正文、表格、图注、风险矩阵和最终结论中重复出现时，每一次必须复用同一原始字符串；禁止因“展示简洁”改变精度。
- 禁止用直接持股与总持股相减推算间接持股，禁止逐层相乘、加总或倒算；接口未单独返回间接持股时，只写“总持股（含间接）”，不得把总持股误标为间接持股。
- 法定阈值、评分权重和区间（如 UBO 识别阈值）按规则原文展示，不属于企业股比返回值，不强制补成四位小数。

> **使用约定**：以下是融资动态追踪报告的**完整骨架**——标题层级、表头与列、免责声明**全部固定**，模型只把 `{}` 占位替换为接口返回值，**禁止新增 / 删除章节、禁止改表列、禁止虚构接口未返回的列或分类**。各章数据来源见每节标注（业务语言，报告内不写工具代码名 / server 名）。融资金额、估值、股权比例、注资金额、退出比例等数值**逐字引用接口原始返回值**，接口未返回写「未披露」，绝不编造、绝不估算补位。
> **填写纪律（务必遵守，对齐本 SKILL 已有铁律）**：
> ① **数据来源逐项标注**（对齐 UNIVERSAL RULES）：每条融资 / 估值数据须标「公开披露 / 估算 / 未披露」，**未披露的金额与估值如实写「未披露」，不得拿其它轮次或自算值顶替**。
> ② **数据零重构（本 SKILL 关键铁律）**：历轮融资金额 / 估值 / 股权比例 / 注资金额一律照抄接口聚合值（如示例中的 `16.8149%` / `0.6211%` / `225 万元`）——**禁止把历轮估值累加求和、禁止据注册资本 / 股本自估市值、禁止把各层 / 各轮持股比例相乘自算稀释后比例、禁止把差额圆场为「四舍五入」**。「累计融资」「股权稀释」仅在接口直接给出聚合值时引用；接口未给聚合值则**逐轮分列、写「未披露」，不自行加总 / 相乘**。表决权若涉及，逐字引用接口值（如 `53.0011%`），不自算。
> ③ **估值合理性 / 趋势 / 信号属定性解读**（对齐 UNIVERSAL RULES「必须分析估值合理性与趋势」「不忽视融资间隔过长警示信号」「竞品必对比」）：只能基于已填入的接口原始数字展开，**不得引入接口未返回的新数字 / 新估值 / 新主体**；估值倍数等比较性表述若接口未直接给出，写「未披露 / 不可比」，不自乘自算。

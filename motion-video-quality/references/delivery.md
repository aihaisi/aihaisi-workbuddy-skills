# 发布：标题 / 标签 / desc 落点 / 事实核验

> **标签只占三成，七成在文案落点。**
> 结论都来自对真实同类作品数据（作品 JSON）的逆向，不是搜来的二手教程。

---

## 1. 标题

### 1.1 形态

同类爆款标题高度一致：**疑问句 + 指向一个日常困惑**（不是指向知识点）。

```
最"笨"的程序，为什么赢了所有老狐狸？
老实人凭什么总吃亏？
谁先开口，谁更如愿？
```

⇒ 主语用**观众手机里/生活里真有的东西**，疑问用**观众真的问过自己的那句话**。

### 1.2 三条硬约束

| 约束 | 理由 |
|---|---|
| 🔴 **标题不能是答案** | 把片中的落点句直接当标题 = 开场剧透 |
| 🔴 **标题要和封面互补，不能重复** | 封面已占"反直觉"，标题就去占"日常现象"；否则信息流里同一句话说两遍 |
| 🔴 **不指向知识点，指向困惑** | "什么是 X 效应"没人点；"为什么会这样"才有人点 |

### 1.3 A/B 打法

**先发主推标题，隔 3–7 天换备选标题重发同一条**（平台支持同一作品换标题），
比发两条内容互相稀释好。

## 2. 标签

### 2.1 三层结构，**总共只打 4–6 个**

```
第 1 层 身份（必带）
    #vibe知识大赏          ← 这个体裁的入场券
    #claude5.5            ← 制作工具标记，等于"我是这一挂的"
    #ai新星计划            ← 平台 AI 创作者扶持（参加时才打）

第 2 层 垂直内容（2–3 个）
    #概率 #随机 #统计学 #博弈论 #辛普森悖论 #诺贝尔奖 #职场 …

第 3 层 泛流量（1–2 个）
    #底层逻辑
```

🔴 **拆过的真实作品里没有一条超过 6 个标签。** 这个体裁靠话题池精准，不靠数量。

### 2.2 已核实的话题 ID（从真实作品的 `text_extra.hashtag_id` 直接读到）

`hashtag_id` 的存在证明这些是**真实话题**，不是猜的。ID 很短 ⇒ 多年前建立的老话题，池子大而稳。

| 话题 | 判读 |
|---|---|
| `#概率` | ⭐ 老话题，池子大（与高分对标作品同池） |
| `#博弈论` / `#诺贝尔奖` / `#职场` | 老话题 |
| `#vibe知识大赏` | 活动话题，ID 与当期作品视频 ID 同段 ⇒ 有档期 |
| `#claude5` | 三条作品共用同一个话题 |
| `#ai新星计划` | 官方扶持活动 |

✅ **`#Claude5.5` 的 `.5` 不参与话题匹配。** 证据：desc 里写 `#Claude5.5`，
但接口记的 caption 跨度是 8 个字符（`#Claude5`）⇒ 话题 token 到 `5` 就结束，
`.5` 是话题之外的普通文本。**写 `#Claude5.5` 还是 `#claude5`、大小写如何，都落到同一个话题。**

⚠️ **但 `text_extra` 不保证完整**：同一次导出里，一条作品解析出 6 个、另一条只有 1 个
（而 desc 明明写了 5 个）。⇒ **统计标签只能信 desc 原文，`text_extra` 只用来拿 ID。**

### 2.3 慎打 / 不打

| 标签 | 原因 |
|---|---|
| `#认知觉醒` `#思维格局` `#人性` | **励志/鸡汤池的强信号**，会把硬知识拖进情绪池 |
| 与内容不搭的争议话题 | 会把内容拉进争议池，且与"数据思维 / 数理科学"的定位不符 |
| 教育焦虑类（`#考研` `#申请季`） | 会掉出科普池 |
| 内容领域之外的大池（如 `#音乐` `#歌单`） | 会把内容误判成别的品类 |
| 互动内容向的活动话题 | 与"知识向"活动话题**别混用** |

## 3. 🔴 落点决定进哪个池（比标签本身重要）

平台的 `video_tag` 是**自动归类**，由文案**最后两句**决定。
**同样的体裁、同样的制作方式，落点不同会被分进完全不同的池：**

| 落点 | 被判进 |
|---|---|
| 停在**现象 / 机制 / 方法 / 认知** | `科普 · 数理科学` ✅ |
| 落到"所以你该怎么做" | `励志 · 鸡汤` ❌ |

**反面实例**：一条讲硬知识（学术竞赛机制）的作品，因为结尾落在
"带上锋芒的善良才是你的护城河"，被归进了 `励志/鸡汤` —— **这是内容的损失**。

⇒ **desc 最后一句必须落回事实，不要落向劝诫。**

```
✅ 真正的随机，不会避着重复走。
❌ 所以，别再被你的直觉骗了。      ← 一写成这样就掉进鸡汤池
```

## 4. desc 结构

**固定前缀**（对照真实作品的写法）：

```
Vibe知识大赏 ｜ 《片名》<一句疑问句标题>

<2–4 行事实概要：某年 + 谁 + 发生了什么 + 结果>

本视频由 #Claude5.5 用代码渲染制作。
```

| 要点 | 原因 |
|---|---|
| **前 55 字内必须出现钩子** | 信息流预览只显示前面一截，钩子必须在折叠前出现 |
| 最后一句**回事实** | 落点决定归类（§3） |
| 把制作工具当卖点摆出来 | 与同类作品格式一致，等于"我是这一挂的" |

## 5. 事实核验表（物料必备）

**屏幕上出现的每一个数字都要有出处**，并在物料里留一张表：数字 → 论文 / 发布会 / 官方博客。

- 数据类选题必须给：数据集来源、年份、样本量。
- 🔴 **"总体率 + 分层率"同时出现时，口径必须写在画面上，且各自的「分母」要标清。**
  两个率**各有各的分母**，不相加等于 100%（观众必然要问）。混用 = 事实错误。
- ⚠️ **"日常现象"和"具体事件"要分清**：如果片中用某个现象做类比，而它并不指向某个可考的具体事件，
  就**不要**给它编 source —— 保持"现象描述"的措辞。

## 6. 取证：怎么判断一条视频是代码渲染还是生成式

**最快、最硬的判据**：400% 放大看画面里的**文字和图表**。

| 观察 | 结论 |
|---|---|
| 文字**锐利**、数值**精确到个位** | **代码渲染**（生成式模型画字必然是扭曲的鬼画符 —— 这是原理决定的，不是调参能解决） |
| 文字有笔画粘连/形变、数字差一位 | 生成式，或生成式后处理 |

⚠️ **别用低阈值在暗背景上数"亮点"** —— 那数出来的是压缩噪声。
正确做法是先做减法（拿同帧号的纯背景作参考）、再按分区报标准差。

**逆向平台数据时的三条**：
- `--dump-dom` 直连多半会被判机器人（验证码中间页）⇒ 必须用 CDP + stealth。
- DOM 里往往只有 `blob:` ⇒ 必须取接口 JSON 里的播放地址，**解析完立刻下载**（签名几分钟就 403）。
- 音频通常在独立的字段里；有些平台还提供**官方节拍检测 JSON**，可用来做减法定位作者加的 SFX。

## 7. 发布前最后三件事

1. **搜一下活动话题是否还挂着活动位** —— 有活动位才有额外流量加权。这类档期数据没有实时接口，**必须人工确认**。
2. **确认背景音乐版权** —— 很多同类作品用的曲子有版权保护、播放地址为空，不能直接拿来用。用可商用曲目或自己合成。
3. **标题 A/B** —— 见 §1.3。
